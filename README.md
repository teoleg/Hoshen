# Hoshen

ADR-based agentic development platform on Claude Code.

Architecture Decision Records are the only driver of development: every piece
of work starts from an approved ADR, agents implement it, and the UI shows the
decisions as a graph.

- [All ADRs](adr/README.md): table of every decision and its status
- [Constraints in force](adr/CONSTRAINTS.md): the rules approved ADRs impose

Hoshen is named after the *hoshen mishpat*, the breastplate of judgment that
held the Urim and Thummim.
